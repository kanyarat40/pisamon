# Pisamon (Forge 1.20.1 + TaCZ)
- ผีชุดดำ: กระสุนธรรมดาไม่โดน / กระสุนอาคม (ammo id ลงท้าย _arkom) โดน + สะเก็ด + วาปหลบ 35%
- มีดอาคม ทำดาเมจใส่ผีได้
- ศาลผีชุดดำใต้ต้นไม้ใหญ่ เจนเองในป่า (หรือสั่ง /place feature pisamon:shrine_tree ~ ~ ~)
## Build
1. โหลด Forge MDK 1.20.1-47.3.x แล้วก๊อป gradlew, gradlew.bat, โฟลเดอร์ gradle มาใส่โฟลเดอร์นี้
2. ใช้ Java 17 แล้วรัน: ./gradlew build   (ได้ไฟล์ใน build/libs/)

## เสียงผี
- กระสุนธรรมดา -> ghost_taunt (หัวเราะ + "มึงทำไรกูไม่ได้หรอก กระสุนกาก ๆ ของมึง") + ข้อความ action bar
- กระสุนอาคม / มีดอาคม -> ghost_wail (ร้องโหยหวน)
- ใส่ไฟล์ .ogg (mono) ที่ src/main/resources/assets/pisamon/sounds/ ชื่อ ghost_taunt.ogg และ ghost_wail.ogg
- ระหว่างยังไม่มีไฟล์ จะใช้เสียง vanilla แทน; พอใส่ไฟล์จริงแล้วแก้ ModSounds.VANILLA_PLACEHOLDER = false

## v0.2 (ใหม่)
- **เลือดผี** ชุดดำ 200 / เสือสมิง 260 (ปรับที่ `Tuning.java` ไฟล์เดียว)
- **ผีเกิดในป่าใหญ่** (jungle, bamboo jungle, dark forest, old growth taiga/birch — แก้ที่ `data/pisamon/tags/worldgen/biome/ghost_forest.json`)
  - กลางคืนเกิดเป็นฝูง ดึกสุดเที่ยงคืนเยอะสุด (สูงสุด 16 ตัวรอบตัว) ฝนตกเยอะขึ้น
  - กลางวันโอกาสเจอน้อยมาก (ต้องอยู่ใต้ร่มไม้ทึบ) และผีที่ไม่ได้ไล่ใครจะจางหายเมื่อสว่าง (ตัวจากศาลไม่หาย)
- **เสือสมิง** พุ่งกระโจนใส่ เลือดต่ำกว่าครึ่งจะคำรามโกรธ เร็ว+แรงขึ้น (สกินยืม ocelot ของ vanilla ขยาย 2.2 เท่า)
- **ห้าง** ในป่า: ขา 5 บล็อก มีบันได พื้น 5x5 ราวกั้น หลังคาฟาง ถังเสบียง (มีโอกาสได้มีดอาคม)
- **นั่งห้าง**: มือเปล่าคลิกขวาที่บันได(stairs)ครึ่งล่าง = นั่ง, Shift = ลุก; ตอนนั่งตาผีรอบ 32 บล็อกจะเรืองแสง
- สั่งวางห้างเอง: `/place feature pisamon:hang ~ ~ ~`
